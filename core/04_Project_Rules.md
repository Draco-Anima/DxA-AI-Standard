# Regeln für Projektregeln

## Aufbau

Jede Projektregel enthält nach Möglichkeit:

- **Status:** Entwurf, bestätigt oder ersetzt
- **Geltungsbereich:** Wofür die Regel gilt
- **Regel:** Eindeutige Vorgabe
- **Beispiele oder Gegenbeispiele:** falls sie Missverständnisse verhindern
- **Quelle/Entscheidung:** Chat, Ticket, Dokument oder Datum

## Priorität

1. Aktueller expliziter Auftrag
2. Bestätigte Projektregel
3. Private nutzerspezifische Vorgabe, sofern sie nicht projektspezifisch ist
4. Bestätigte Kernregel
5. Vorlage oder Vorschlag

Widersprüche werden nicht still aufgelöst. Sie werden sichtbar gemacht und bestätigt.
