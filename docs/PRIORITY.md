# Regelpriorität

Für die Anwendung des Standards gilt grundsätzlich:

1. aktueller ausdrücklicher Auftrag,
2. bestätigte Projektregeln,
3. private projektübergreifende Nutzerkonfiguration,
4. relevante Kernregeln,
5. Vorlagen, Vorschläge und unbestätigte Entwürfe.

Eine niedrigere Ebene darf eine höhere nicht stillschweigend überschreiben. Widersprüche werden sichtbar gemacht. Eine neuere bestätigte Entscheidung ersetzt einen älteren Stand nur innerhalb desselben Geltungsbereichs.

Die fachliche Wahrheit eines Projekts stammt weiterhin aus dessen maßgeblichen Fachquellen. Die Prioritätsfolge regelt die Arbeitsweise, nicht den fachlichen Inhalt dieser Quellen.
