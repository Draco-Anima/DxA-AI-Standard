# Learning und Tutorials

Die verbindlichen Regeln liegen in `projects/learning/README.md`.

Die Trennung erfolgt nach dem Arbeitsziel:

- **Learning:** Verständnis und eigenständiges Erarbeiten stehen im Vordergrund.
- **Tutorial:** Eine vollständige reproduzierbare Anleitung steht im Vordergrund.
- **Projektarbeit:** Entwicklung, Änderung oder Fehlerbehebung eines realen Projekts bleibt reguläre Projektarbeit, auch wenn dabei Erklärungen notwendig sind.

Reine Learning- und Tutorial-Kontexte lösen keine `.work/`- oder Repository-Entscheidung aus.
