# Private Overlay

Die öffentliche Distribution kann als allgemeine Basis verwendet und privat erweitert werden.

Eine private Arbeitsumgebung darf beispielsweise enthalten:

- eine persönliche `USER.md`,
- konkrete Projektregeln,
- projektspezifische Verweise auf Fachquellen,
- persistierte temporäre `.work/`-Arbeitsstände.

Diese privaten Inhalte verändern nicht automatisch den öffentlichen Standard. Allgemein nutzbare Verbesserungen werden bewusst bereinigt und über den in `PUBLICATION.md` beschriebenen Prozess zurückgeführt.

Damit bleibt die öffentliche Basis wiederverwendbar, während private Arbeitsumgebungen projektspezifische und persönliche Informationen enthalten können.
