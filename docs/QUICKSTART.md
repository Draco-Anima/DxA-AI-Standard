# Quickstart

1. `core/00_Workflow.md` als zentrale Ablaufregel verwenden.
2. Relevante Checklisten aus `core/` je nach Aufgabenart ergänzen.
3. Optional `templates/USER.md` in der privaten Arbeitsumgebung als `USER.md` anlegen.
4. Für ein reales Projekt eine passende Vorlage aus `templates/` verwenden und bestätigte Regeln dort festhalten.
5. Für reine Lernaufgaben `projects/learning/README.md` verwenden.
6. `.work/` nur nach der Workflow-Entscheidung verwenden und niemals als öffentliche Fachquelle behandeln.

Für eine öffentliche Weiterentwicklung dieses Repositories gelten `CONTRIBUTING.md` und `PUBLICATION.md`.
