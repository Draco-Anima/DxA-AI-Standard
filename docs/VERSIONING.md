# Versionierung

DxA-AI-Standard verwendet Semantic Versioning als Orientierung.

- **MAJOR**: grundlegende inkompatible Änderungen am Arbeitsmodell oder an zentralen Regeln.
- **MINOR**: neue rückwärtskompatible Regeln, Bereiche, Vorlagen oder Fähigkeiten.
- **PATCH**: Korrekturen, Präzisierungen und kleinere dokumentarische Verbesserungen ohne neue fachliche Anforderungen.

Vor `1.0.0` kann sich der Standard noch stärker entwickeln. Die erste öffentliche Fassung wird als `0.1.0` geführt.

Relevante Änderungen werden in `CHANGELOG.md` dokumentiert. Tags und GitHub Releases markieren veröffentlichte Stände; `main` enthält den stabilen veröffentlichten Stand.
