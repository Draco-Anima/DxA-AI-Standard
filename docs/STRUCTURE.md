# Repository-Struktur

```text
DxA-AI-Standard/
├── .github/                 # GitHub-Workflow und Contribution-Vorlagen
├── core/                    # Allgemeine verbindliche Arbeitsregeln
├── docs/                    # Öffentliche Dokumentation
├── projects/
│   └── learning/            # Allgemeine Learning-/Tutorial-Regeln
├── scripts/                 # Public-Safety-Prüfungen
├── templates/               # Neutrale Vorlagen
├── CHANGELOG.md
├── CONTRIBUTING.md
├── LICENSE
├── PUBLICATION.md
├── README.md
└── SECURITY.md
```

Nicht Teil der öffentlichen Struktur sind eine ausgefüllte Root-`USER.md`, tatsächliche `.work/`-Arbeitsstände und konkrete private Projektordner.
