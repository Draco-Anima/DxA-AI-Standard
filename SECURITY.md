# Security Policy

## Reporting

Bitte veröffentliche keine Secrets, Zugangsdaten oder personenbezogenen Daten in einem öffentlichen Issue.

Für sicherheitsrelevante Funde soll die private Vulnerability-Reporting-Funktion des GitHub-Repositories verwendet werden, sofern sie verfügbar ist.

## Public-Safety-Grenze

Als Veröffentlichungsfehler gelten insbesondere versehentlich eingecheckte private Nutzerkonfigurationen, tatsächliche `.work/`-Arbeitsstände, private Projektdaten oder Secrets. Solche Inhalte sollen nicht über ein öffentliches Issue reproduziert oder zitiert werden.
