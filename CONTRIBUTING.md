# Contributing

Beiträge zu DxA-AI-Standard sind willkommen.

## Workflow

1. Einen eigenen Branch vom aktuellen `main` erstellen.
2. Änderungen auf den tatsächlich beabsichtigten Umfang begrenzen.
3. Keine persönlichen Nutzerprofile, privaten Projektdaten, Secrets oder `.work/`-Arbeitsstände einbringen.
4. Dokumentation und betroffene Querverweise aktualisieren.
5. Den Public-Safety-Check lokal beziehungsweise im Pull Request bestehen lassen.
6. Pull Request gegen `main` eröffnen und Zweck sowie relevante Änderungen beschreiben.
7. Review-Kommentare und offene Gespräche vor dem Merge auflösen.

## Öffentliche Inhalte

Zulässig sind insbesondere allgemeine Regeln, Checklisten, neutrale Vorlagen und allgemein nutzbare Learning-/Tutorial-Regeln.

Nicht in dieses Repository gehören ausgefüllte private `USER.md`, konkrete private Projektregeln oder Projektdaten sowie tatsächliche `.work/`-Verzeichnisse.

## Änderungen am Standard

Neue Regeln sollen eindeutig formuliert, ihrem Geltungsbereich zugeordnet und mit bestehenden Regeln auf Widersprüche geprüft werden. Bestehende Regeln werden nicht stillschweigend durch ähnlich formulierte neue Regeln ersetzt.
