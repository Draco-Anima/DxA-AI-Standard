# Veröffentlichung aus einem privaten Arbeitsstandard

DxA-AI-Standard ist als öffentliche Distribution gedacht. Eine private Arbeitskopie kann zusätzliche Nutzer- und Projektdaten enthalten, darf aber nicht ungeprüft gespiegelt werden.

## Veröffentlichungsgrenze

Vor einer Übernahme in dieses Repository gilt:

- Nur allgemeine, wiederverwendbare Regeln und neutrale Vorlagen übernehmen.
- Keine tatsächliche `.work/`-Struktur oder deren Inhalte übernehmen.
- Keine ausgefüllte private `USER.md` übernehmen.
- Keine konkreten privaten Projektordner oder projektspezifischen Daten übernehmen.
- Keine Secrets, Zugangsdaten oder personenbezogenen Informationen übernehmen.
- Änderungen gegen bestehende öffentliche Regeln auf Widersprüche prüfen.

## Verfahren

Private Änderungen werden bewusst ausgewählt, bereinigt und über einen eigenen Branch sowie Pull Request in die öffentliche Distribution übertragen. Git-Historie eines privaten Quell-Repositories wird nicht in die öffentliche Distribution übernommen.

Der automatisierte Public-Safety-Check ist eine zusätzliche technische Schranke und ersetzt nicht die inhaltliche Prüfung vor einer Veröffentlichung.
